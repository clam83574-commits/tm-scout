# tm-scout — игроки без агента с Transfermarkt

Контекст, цифры пилота и юридические флаги — в `SOFTWARE.md`, запись `tm-scout`.
Здесь только как запускать.

## Установка

```bash
pip install requests beautifulsoup4 lxml playwright
playwright install chromium
```

Chromium обязателен: Transfermarkt закрыт AWS WAF, и браузер нужен, чтобы
один раз пройти JS-челлендж и получить куку `aws-waf-token`. Дальше страницы
тянет обычный `requests` — быстро.

## Сбор

```bash
python scout.py --comps L1,L2,L3
```

- `--comps` — коды лиг через запятую (см. `COMPETITIONS` в `scout.py`).
- `--clubs N` / `--players N` — лимиты для быстрой пробы.
- `--headed` — показать окно браузера (отладка челленджа).
- `--export` — только пересобрать CSV из готовой базы.
- `--normalize` — досчитать поля сортировки (`mv_eur`, `contract_iso`).

Германия целиком (3 дивизиона, ~1580 игроков) — около 48 минут.
Темп намеренно вежливый: пауза 1–1.9 сек между запросами.

Результат: `data/scout.sqlite` и `out/candidates.csv` (разделитель `;`,
кодировка UTF-8 с BOM — Excel открывает без плясок).

## Бот — @tranfer_no_agents_bot

```bash
python bot.py
```

Токен и список допуска лежат в `.env` рядом с `bot.py` (файл под `.gitignore`,
в репозиторий не уходит):

```
TM_BOT_TOKEN=...        # от @BotFather
TM_BOT_ALLOW=           # пусто = отвечает ВСЕМ; сюда id через запятую
```

**Пока `TM_BOT_ALLOW` пуст, бот ответит любому, кто найдёт его по имени.**
Свой id узнаётся командой `/whoami` — она работает и для тех, кому доступ
ещё не выдан, чтобы человеку было что прислать владельцу.

Бот читает ту же `data/scout.sqlite`, поэтому отвечает мгновенно и в момент
запроса на Transfermarkt не ходит.

Навигация: `/start` → лига → клуб или вся лига → карточки со ссылками на TM.
Сортировка списка — по точности, цене, возрасту, сроку контракта.
Текстом можно прислать фамилию — найдёт игрока.

Фильтр — три независимых переключателя (🟢 нет агента / 🟡 семья / ⚪ пробел),
включаются любой комбинацией. По умолчанию все три.

## Таблицы в базе

- `players` — текущий срез. `agent_status`: `AGENT` / `NO_AGENT` /
  `RELATIVES` / `UNKNOWN`.
- `changes` — история изменений, пишется сама при каждом прогоне.
  Ради неё всё и затевалось: строка `agent_status: AGENT → NO_AGENT`
  означает, что у игрока закончился контракт с агентством.

## Чего здесь ещё нет

- кнопка «обновить клуб» в боте (точечный до-парсинг ~25 страниц);
- расписание еженедельного прогона и рассылка диффа «агент пропал»;
- выгрузка в Google Sheets;
- пометка «⚪ у дорогого игрока в топ-лиге = скорее пробел в базе TM,
  чем свободный игрок» — решение владельца ещё не принято.
